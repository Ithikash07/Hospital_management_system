# 🏥 Hospital Management System

A responsive and interactive **Hospital Management System** built entirely using **React.js**, **HTML**, **CSS**, and **Bootstrap**, with **Local Storage** used as the data layer for handling user data and session persistence.

---

## 🚀 Project Overview

This project simulates a hospital management system UI with patient registration, authentication, admin panel, appointment handling, and patient list display. It is built using only front-end technologies and is perfect for learning the fundamentals of React, component structure, and working with browser storage (localStorage).

---

## 🛠️ Tech Stack

- **React.js** – Component-based UI architecture
- **HTML5** – Markup structure
- **CSS3** – Custom styling
- **Bootstrap 5** – Responsive design and utility classes
- **JavaScript (ES6+)** – Logic and interactions
- **Local Storage** – Storing users and appointment data

---

## 📦 Features

- 👥 **User Registration & Login**
  - Secure and validated signup/login forms
  - Only unique email registrations allowed

- 🩺 **Admin Dashboard**
  - View list of all registered patients
  - Live search functionality
  - Export patient list as CSV

- 🗓️ **Appointments**
  - Patients can request appointments
  - Appointment history is visible to users

- 🛡️ **Role Handling**
  - Admin login (default: `admin@admin.com`) excluded from patient list
  - Patient users have access to request and view appointments only

- 📤 **Data Storage**
  - All user and appointment data are managed via browser's **localStorage**
  - No external backend required
